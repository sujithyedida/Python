# 🧩 Data Structures & Algorithms in Python

Welcome to the **DSA** module! This section contains clean, optimized Python implementations of fundamental data structures and algorithmic patterns, essential for coding interviews, competitive programming, and efficient software engineering.

---

## 📌 Topics Covered

### 1. Linear Data Structures
* **Arrays & Lists:** Dynamic array operations, slicing, and memory concepts.
* **Strings:** Manipulation, pattern matching, two-pointer techniques, and anagrams.
* **Linked Lists:** Singly and doubly linked lists, node insertion, deletion, and reversal.
* **Stacks & Queues:** LIFO and FIFO implementations using lists and `collections.deque`.

### 2. Hierarchical & Non-Linear Data Structures
* **Trees:** Binary Trees, Binary Search Trees (BST), traversals (Inorder, Preorder, Postorder, Level-order).
* **Graphs:** Adjacency list representation, Breadth-First Search (BFS), and Depth-First Search (DFS).
* **Hash Maps / Dictionaries:** Frequency counting, collision handling concepts, and lookup optimizations.

### 3. Algorithms & Problem-Solving Patterns
* **Searching & Sorting:** Linear search, binary search, merge sort, quick sort.
* **Two Pointers & Sliding Window:** Efficient array/string traversal techniques.
* **Recursion & Backtracking:** Base cases, call stacks, N-Queens, and subsets.
* **Dynamic Programming (Intro):** Memoization and tabulation (Fibonacci, Knapsack).
