# 📊 Python Data Types & Structures

Welcome to the **Data Types** module! In Python, variables can store data of different types, and different types can do different things. Python has built-in data types grouped into specific categories.

---

## 📌 Categories of Built-in Data Types

* **Numeric Types:**
  * `int`: Whole numbers (e.g., `42`, `-3`)
  * `float`: Numbers with decimal points (e.g., `3.14`, `-0.001`)
  * `complex`: Numbers with a real and imaginary part (e.g., `3 + 5j`)

* **Sequence Types:**
  * `str`: Text/string of characters (e.g., `"Hello, World!"`)
  * `list`: Ordered, mutable sequence of items (e.g., `[1, "apple", 3.5]`)
  * `tuple`: Ordered, immutable sequence of items (e.g., `(1, "apple", 3.5)`)
  * `range`: Represents a sequence of numbers, often used in loops (e.g., `range(0, 10)`)

* **Mapping Type:**
  * `dict`: Key-value pairs, mutable and unordered/ordered insertion (e.g., `{"name": "Alice", "age": 22}`)

* **Set Types:**
  * `set`: Unordered collection of unique items (e.g., `{1, 2, 3}`)
  * `frozenset`: Immutable version of a set

* **Boolean Type:**
  * `bool`: Represents truth values—either `True` or `False`

* **None Type:**
  * `NoneType`: Represents the absence of a value or a null value (`None`)

---

## ⚖️ Mutable vs. Immutable Data Types

Understanding whether an object can change after creation is crucial in Python:
* **Mutable (Can be changed):** `list`, `dict`, `set`
* **Immutable (Cannot be changed):** `int`, `float`, `str`, `tuple`, `bool`
