# 01. Python Basics 🐍

Welcome to the **Basics** module! This section covers the fundamental concepts of Python programming, laying the groundwork for data structures, object-oriented programming, and advanced data applications.

---

## 📌 Core Topics Covered

* **Syntax & Output:** Print statements, comments (`#`), and Python execution flow.
* **Variables & Data Types:** Integers (`int`), Floats (`float`), Strings (`str`), and Booleans (`bool`).
* **Operators:** 
  * Arithmetic (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
  * Comparison (`==`, `!=`, `>`, `<`, `>=`, `<=`)
  * Logical (`and`, `or`, `not`)
  * Assignment (`=`, `+=`, `-=`, etc.)
* **Type Conversion & Typecasting:** Implicit vs. explicit type conversion (`int()`, `str()`, `float()`).
* **User Input:** Working with `input()` and parsing string inputs to numeric types.
* **Control Flow & Conditionals:** `if`, `elif`, `else` statements and nested conditions.
* **Loops & Iteration:**
  * `for` loops and `range()` function
  * `while` loops
  * Loop control statements: `break`, `continue`, `pass`
* **Functions Basics:** Defining functions (`def`), parameters, return values, and default arguments.
